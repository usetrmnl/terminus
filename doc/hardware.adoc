= Hardware

We support {raspberry_pi_link} and {orange_pi_link} hardware. We also use and test Terminus on the following:

* link:https://www.raspberrypi.com/products/raspberry-pi-5[Raspberry Pi 5]: Recommended due to great performance and feature set.
* link:https://www.raspberrypi.com/products/raspberry-pi-zero-2-w/[Raspberry Pi Zero 2 W]: Good if you want a compact form factor and don't care about speed.
* link:http://www.orangepi.org/html/hardWare/computerAndMicrocontrollers/details/Orange-Pi-Zero-3W.html[Orange Pi Zero 3W]: Provides the compact size (nearly) of a Raspberry Pi Zero 2 W with the power of a Raspberry 5 at a lower cost (does run warmer, though).

== Setup

To setup multiple devices, use the {pi_link} to configure, flash, and manage multiple device profiles. The Pi project provides Bash shell scripts for formatting, flashing, and spinning up Terminus. This includes scripts for {sensor_project_link} and Terminus itself. You can even override or as you own scripts as well!
